### Who Are You? Again

Okay, I am Aspen Schneider, an open-source software developer. I love the Linux desktop, but I'm not deeply interested in the kernel. Instead, my big interest is the Linux user space.


### What Are You Developing?

I'm mainly developing [Swingby](https://github.com/aspschn/swingby). This is a GUI engine for Wayland which supports C APIs.
Since Wayland is just a protocol, this doesn't have drawing features, and has very low-level event mechanisms. I'm filling the gap between the low-level Wayland client protocols and real GUI toolkits.

I hope there's the 3rd choice of GUI toolkit in the GTK vs Qt world, using my engine.
